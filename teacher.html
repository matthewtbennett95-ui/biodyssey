Teacher guide

Teaching with Biodyssey

Free biology games, one world per unit. No accounts or setup.

The worlds

A class period

  1. Post the world's link in Google Classroom (use Copy link above).
  2. Students play. Each world shows its goal and a harder stretch goal.
  3. Students write in Notes (top bar) using the prompts. All notes print together as a study guide.
  4. Before the bell, students tap Back up, especially on Chromebooks that wipe data at sign-out.

Turning work in

  • Printouts: each game's Print my results, and My notes → Print study guide. Students choose Save as PDF and attach it in Classroom.
  • Save codes: if files are blocked, students copy a save code into a Google Doc or a private Classroom comment. Restoring a save code on any device brings everything back.

Answer guides and teacher tools

  • Codon Rush checks every answer as students go, and its results list exactly what to review.
  • Symbio has its own Teacher tab: a lesson plan, an answer guide, standards (Georgia CTAE and NGSS) and teacher mode.

Safety

No accounts, no personal data, nothing sent anywhere, no student-to-student contact. The Safety and privacy page is written so you can share it with families or administrators.
