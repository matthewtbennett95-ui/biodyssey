# Biodyssey

*A journey through the worlds of biology.*

Biodyssey is a free website of biology games for high school classrooms. Students travel from world to world, practicing a different part of biology in each one. They save their progress, keep their own notes, and print those notes as a study guide.

- **No accounts:** anyone can use it, and no personal data is collected.
- **Progress saves automatically** in the browser. Students can also back it up as a save file or a save code and restore it on any device.
- **Works on Chromebooks and phones.**

Status: being designed. See [`docs/DESIGN.md`](docs/DESIGN.md).

The first world is based on [Symbio](https://matthewtbennett95-ui.github.io/symbiosis/), a game about the evolution of cooperation.
