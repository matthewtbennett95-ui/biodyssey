Safety and privacy

Nothing leaves the device.

A plain-language summary for students, families and schools.

What Biodyssey collects

Nothing. There are no accounts, logins, student numbers or email addresses. Biodyssey has no server of its own, and it uses no analytics, ads, cookies or trackers.

Where progress is kept

  • Progress and notes are saved only in the browser on this device. Teachers can't see them, and neither can the people who make Biodyssey.
  • Clearing browsing data, or a Chromebook that wipes data at sign-out, deletes them. That's why every page has Back up.
  • A backup (a save code or a save file) is made only when a student chooses to, and it goes only where the student puts it, such as a Google Doc or a private Classroom comment.

Names

A name is optional. It is only asked for on printouts, so a teacher knows whose work it is, and it stays on the device.

How this is enforced

Every page carries a security rule (a Content Security Policy) that tells the browser the page may not send data anywhere. Fonts and code are served from this site, so a student's browser doesn't contact other companies just by opening a page.

The one outside service

Symbio's opening chapter shows a short, teacher-chosen video clip. It plays from YouTube in privacy-enhanced mode (youtube-nocookie.com), with no related videos. YouTube is contacted only on that chapter, to play the clip. If a school network blocks YouTube, the page says so, and the teacher can show the clip to the class.

Like any website, Biodyssey is delivered by a web host (GitHub Pages), which receives the standard information any browser sends when it loads a page.

Students and each other

There is no chat, no shared board and no public leaderboard. Students never see each other's names or scores in Biodyssey.

The content

Every world is checked for scientific accuracy against published research, and for classroom appropriateness, before it goes live.
