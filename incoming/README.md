# Incoming games

Upload a game here (on GitHub: **Add file → Upload files**) to bring it into Biodyssey. See `docs/DESIGN.md`.

Games that have already been brought in are kept, unchanged, in `_archive/incoming/`. With GitHub Pages' standard settings, folders that start with an underscore are not published on the website, so old versions (for example, ones with logins) stay off the live site.
